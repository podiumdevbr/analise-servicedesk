# 📊 Painel Gerencial de Atendimento - Service Desk (TRE-PB)

Dashboard interativo desenvolvido para o acompanhamento gerencial e auditoria dos atendimentos multicanal do Tribunal Regional Eleitoral da Paraíba (TRE-PB).

## 🚀 Funcionalidades
- **Métricas de Atendimento:** Volume total, taxa de resolução e incidência de áudios.
- **Análise Semântica:** Distribuição por assuntos principais, status de solução e avaliação de cordialidade dos operadores.
- **Picos de Demanda:** Gráfico dinâmico com os horários de maior fluxo de chamadas.
- **Filtros Dinâmicos:** Filtragem por atendente, status e assunto.
